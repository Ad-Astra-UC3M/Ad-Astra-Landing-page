# Asset attribution

- Earth imagery is based on NASA Earth observation datasets. NASA imagery is
  used in accordance with the [NASA media usage
  guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).
- Normal, specular and Milky Way source maps are from [Solar System
  Scope](https://www.solarsystemscope.com/textures/) and are distributed under
  the [Creative Commons Attribution 4.0 International
  license](https://creativecommons.org/licenses/by/4.0/).
- The textures in this directory have been resized, converted or color-adjusted
  for real-time rendering on the web.
